# Product photography

One file per product, named for the product's slug — `Product.id` with the
`prod_` prefix removed — with a `.jpg`, `.png`, `.webp` or `.avif` extension:

    prod_amul-taaza-milk-500-ml  →  amul-taaza-milk-500-ml.jpg

Drop the file in and it is picked up automatically; `src/lib/productImages.ts`
builds the map from this directory's contents. A file whose name matches no
product fails `product-images.test.ts`, so a typo cannot quietly render
nothing.

**Each photograph must show that exact product.** A category photo standing in
for a specific SKU is the thing this directory exists to replace — a product
with no file of its own falls back to category photography and then to a
neutral tile, which is honest; a bag of generic flour captioned "Aashirvaad
Superior MP Atta 5 kg" is not.

Square crops, roughly 480×480, under ~80 KB each.

`REQUIRED.md` lists every product still without a file. It is regenerated by
the test suite.
